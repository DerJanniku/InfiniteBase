# Roadmap

## MVP (Phase 1)
- Dockerized baseline (`frontend`, `backend`, `postgres`, `qdrant`)
- Node CRUD API in Rust
- Basic infinite canvas in Next.js
- Drag-and-drop file node creation
- Visual Trash (soft delete)

## Phase 2
- Prompt-Node + graph-scoped context
- Agent action endpoint with validation
- Semantic search via vector retrieval
- History timeline and action audit

## Phase 3
- Snapshots + restore workflows
- Conflict resolution UI for file sync issues
- Advanced exports (interactive read-only share)
- Plugin system for custom node types

## Phase 4
- Optional paid cloud sync/multiplayer
- E2E encrypted collaboration channels
- Managed agent marketplace/integrations

## Milestone Intent
- Milestone A: usable personal board for study/work
- Milestone B: reliable AI-assisted context workflows
- Milestone C: community-ready OSS core
