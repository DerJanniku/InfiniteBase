# Security Policy

## Supported Versions
Security fixes are provided on the `main` branch.

## Reporting a Vulnerability
Please do not open a public issue for sensitive vulnerabilities.

Report privately to:
- `jannik.maier.jm@proton.me`

Include:
- affected area
- reproduction steps
- impact assessment
- suggested mitigation (if available)

## Disclosure
We aim for coordinated disclosure after a fix is available.
